# Perle Rare — Windows Cursor kit (MariaDB read-only)

Copy this whole folder to your Windows PC. Follow **START-HERE.md**.

## Contents

| File | Purpose |
|------|---------|
| `START-HERE.md` | Step-by-step setup |
| `mcp.json` | Ready MCP config (copy into Cursor) |
| `credentials.env` | Connection details |
| `CURSOR-PROMPT.md` | Paste this in Cursor Agent to use the DB |
| `check-setup.ps1` | Optional: verify Node.js is OK |

## Access

- **Read-only** (`SELECT` only) on database `perle-rareinfo`
- Host `142.4.216.57` port `17075`
- No INSERT / UPDATE / DELETE
